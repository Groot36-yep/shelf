Connect your Plex server

Shelf sends your renamed files straight to your server over SSH, the same secure way FileZilla does. They never go through the internet.

From FileZilla

Shelf read these from FileZilla on this PC, only because you opened this. The password stays on this PC.

Your server
Server fingerprint

Every server has its own fingerprint. Shelf will remember this one, and if it ever changes, Shelf will stop before sending your password or any file. That way no other device on your network can pretend to be your server.

Want to be sure? Check it on the server

On your Ubuntu server, run this and check the long code matches:

ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub
